# Detroit Root Network — Director Q preview

Saved September 15, 2026. Proposed design only; not a deployed product update.

## Open and share

Open `DRN-Q-Interactive-Preview.html` in Edge, Chrome, or another modern browser. Send a copy of that file to Quinn. It has no expiration and does not require a running development server, a login code, or database access. No credentials are included.

The file contains the interface and sample data. Form changes and review notes last only until refresh or closing. Copy the review notes into a message or document before closing. Nothing is sent automatically.

## Review tasks

1. Choose Sell. Try the farm profile, selling location, inventory add/edit/sold-out/delete, and manual volunteer posting controls.
2. Choose Both, then explore the growing plan and harvest notebook. These are proposed additions; planning forecasts do not become sale inventory.
3. Explore optional volunteer suggestions and the public invitation preview.
4. Open Community view to compare the lighter customer treatment with the farmer workspace.
5. Expand Director Q review notes and record what works, what is missing, and what should change. Copy the collected notes before closing.

## Proposed brand direction

Forest-green identity and navigation, warm cream surfaces, muted leaf-green accents, and serif headings. Keep the customer discovery experience lighter while carrying the same recognizable DRN identity. This is a proposal for review, not a live restyle.

## Keep the work

`DRN-Farmer-Preview-Source.html` is the editable source. `DRN-Q-Interactive-Preview.html` is the standalone version for sharing. Both are saved in the project docs folder. Commit these files and this guide to Git to preserve a versioned backup. The dated review ZIP is another portable snapshot.

## Prototype limits

Controls demonstrate a flow using sample data; no database writes, authentication, authorization enforcement, actual forecast calculation, or real volunteer publishing occur. Some saves show a confirmation rather than reproducing the complete production behavior. The live app's Supabase permissions and T2 protection remain separate from this mockup.
